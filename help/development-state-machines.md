# 开发指南：交互状态、竞态与回归测试

本文记录应用中没有统一状态转换表、但实际依赖事件顺序的流程，以及维护时必须保持的约束。联合类型、`$state` 或 `status` 字段并不等于完整的状态机；转换还可能藏在 `$effect`、Promise、DOM 焦点、CSS 布局和递归调用栈中。

范围包括 `src/` 和构建脚本；不把依赖、生成产物、普通 CSS hover、纯数据分类函数计为独立业务状态机。独立设计原型不是生产实现，也不在应用回归测试的保障范围内。

## 本次排查发现与处理

原有测试覆盖了大量解析与正常交互路径，但浏览器用例通常在每次操作后等待 URL 更新，且只从页面内按钮切换模式。这会遗漏同批次更新、其他导航入口、混合输入设备和异步乱序。

## 维护约束

### 1. URL 是持久视图，不是全部临时状态

- 读取有效地址使用 `page.shallow?.url ?? page.url`。连续 shallow 更新后只读 `page.url` 可能得到旧状态。
- 初始化必须使用 `view-state.ts` 的归一化函数，与首屏 bootstrap 共享默认值、取值范围和重复参数规则。标量参数取首值，family 可以多值；无关参数不应隐藏普通首屏。
- 不要基于尚未提交的旧 URL 连续发送互不包含的补丁。Explorer 每次写入 element、family、display、temperature 的完整快照；Trends 写入 property、view、period 的完整快照。
- 修改温度必须同时进入 phase；温度限制在 0–6000 K。非 phase 时控件仍保存温度，但必须不可交互。
- `createViewLinkWriter` 与 layout 的 `beforeNavigate` 共同处理**最新意图的提交权限和确认**。不要只复用 writer 却移除提交守卫：过时 transport 仍可能晚于新请求完成。它不是浏览器事务回滚，也不能取消已发生的 History 提交。
- 每个使用 writer 的组件在 onDestroy 调用 dispose；输入废弃旧计算时调用 invalidate。普通导航和 popstate 切换 epoch；失效时立即返回未确认，旧 transport 最终完成后才释放提交守卫记录，避免它复活。
- 可选链接写入失败后，Explorer/Trends/详情保留当前显示并提示；此时复制地址或刷新仍可能得到旧视图，不能声称已保存。后续交互会再次写入当前状态。
- Compare 使用另一种协议：选择以归一化 URL 为准，pending 期间不接收新修改，不排队；失败保留原选择并释放锁。缺少 `elements` 是默认选择，`elements=` 才是明确清空，不能混淆。
- Calculator 的有效结果先在本地生成；History 失败不撤销结果，但提示分享链接未更新。输入事件和新提交必须同步 invalidate 旧请求，不能让旧 URL effect 覆盖新草稿或新错误。`lastUrlFormula` 防止相同逻辑公式的无关 URL 更新覆盖草稿；它不代表输入框和结果始终相同。

### 2. 预览来源必须独立，操作不能在失焦时换对象

首页预览优先级为：

```text
锁定元素 > 鼠标悬停元素 > 键盘预览上下文 > 默认 Carbon
```

- 鼠标离开只清除自己的来源，不能清除仍有效的键盘上下文。
- 键盘焦点进入预览操作区或快捷质量按钮时保留元素上下文，避免按下显示为 “Add H” 的按钮，在 blur 后却添加 C。
- 焦点离开上述交互上下文时清除键盘临时预览。新增预览操作应放进 `.preview-actions`，否则需要同步更新焦点归属逻辑和测试。
- 点击锁定；再次点击已锁定元素进入详情，不是取消锁定。筛选只改变匹配展示，不自动清除锁定元素。
- 移动 grid 隐藏未匹配元素；完整 table 仍显示它们。键盘邻居必须使用实际 CSS 布局、实际列数和可见候选，不依靠设备名称猜测。
- 保持单份 118 个元素节点。选择、预览和真实 DOM 焦点是不同状态，不要从其中一个反推另外两个。
- resize 隐藏当前焦点时转到最近的可用元素；焦点已转到表外或窗口失焦时不主动夺回。ResizeObserver 必须在组件卸载时断开。

### 3. 快捷质量、弹窗与焦点恢复

- `massSelection` 是有顺序的添加历史，不只是元素计数字典。Undo 必须删除最后一次添加；只有最后一个原子被撤销时才关闭。
- 清空质量面板后先等待 `tick()`，再聚焦最近的添加入口；入口已隐藏或移除时回退快捷质量按钮。
- 弹窗展示对象是打开时的元素快照。打开时同时锁定预览，关闭不清除元素锁定。
- 传入真实触发按钮，不假设 `document.activeElement` 就是入口。通过共用 focus helper 检查真实可用性；连接和布局框不代表能聚焦。弹窗不可用入口回退 `main`，质量入口回退快捷添加按钮。导航卸载时恢复滚动，但由路由处理焦点。
- 保存并恢复原 body overflow，而不是一律写成空字符串。
- 背景关闭要求主按钮 pointerdown 和 click 都在背景，不能把内容区拖向背景当作关闭。pointercancel 和消费 click 都要清除残留标志。
- Escape 有层级：配置弹窗存在时先处理弹窗，不能穿透清空快捷质量。
- 焦点循环必须读取当前可用控件；复制按钮在 pending 时可能禁用。

### 4. 电子排布与剪贴板异步结果

- 请求视图 `view` 与实际视图 `activeView` 不同。数据不可展开时实际视图降级 Short，Full/By shell 禁用，保留原始记法与原因。
- 复制请求属于 `(element.number, activeView, copyText, revision)`，不是“这个组件曾经点过 Copy”。
- 切视图/元素后旧成功、旧失败以及旧 finally 都不能污染新请求的反馈或 pending；A→B→A 同样要区分请求代次，包括所有转换都在同一轮事件内完成的情况。
- pending 必须在处理器中同步检查；仅在模板上 disabled 不足以阻止 DOM flush 前的第二次调用。上下文同步不能在后续 effect 中再次误清除已经属于新上下文的请求。
- 测试应使用可控 Promise，而不是任意 sleep：让 B 先完成、A 后失败；再验证新 A 仍 pending，最后只由新 A 的结果提交反馈。
- 卸载旧弹窗后重新打开是新实例；旧实例的异步结果不能使新按钮变成 Copied。
- UI 的版本隔离**不等于取消操作系统的剪贴板写入**。当前测试模拟 API 完成顺序，不证明真实系统剪贴板在跨请求乱序时最终保存哪份文本。

### 5. 图表与趋势表格

- 趋势表格搜索只属于 Data。无论通过按钮、URL、顶部导航还是历史恢复进入 Chart，都不能让隐藏搜索影响图表、覆盖数或极值。
- 图表复制并按原子序数排序输入；坐标、路径、方向键、下拉顺序必须使用同一序列。
- 空集合不能借用全局默认元素；没有元素时也没有可操作 slider。全部测量缺失则仍可显示元素，但值必须是 Unknown，没有数据点。
- 数值 0 是实测值，应保留数据点。缺失测量和原子序数断档都要断开折线。
- `selectedNumber` 离开集合后清空，不在扩大集合时复活；仍在集合内则保留。改变 trend 或外部 active 会重置内部选择，外部 active 仍由调用方控制。
- 单个元素和未测量宽度也必须得到有限坐标；SSR 的默认宽度不能掩盖客户端尺寸测量问题。
- 搜索、换周期、换属性、换排序键后重置页码；换图表清搜索。缺失值在正反排序中都排后面，不能当作 0。

### 6. 计算器、解析器和工程脚本

- 计算器区分当前草稿、上次成功结果和错误：编辑不自动重算；失败清空结果；纠正输入并再次提交才清除旧错误。不要把旧结果显示为新草稿的结果。
- 化学式解析器是有递归栈的下推过程，不只是正则匹配。保留长度 4096、嵌套最多 32 层、正安全整数、括号匹配和元素符号校验。
- 电子排布展开保留源顺序和占据数；检查核心循环、轨道容量、重复轨道及电子总数。壳层来源差异不能靠 UI 静默改数据。
- `getPhaseAtTemperature` 是无历史的温度分类函数，不模拟滞后、压力变化或等离子体；不应为了“显式状态机”改成依赖先前相态。
- 数字格式缓存没有淘汰策略；当前 UI 只使用固定的少量格式配置。若未来开放用户生成任意配置，再评估缓存边界。
- 模板 watcher 用 Promise 链串行重建，catch 后必须能处理下一次事件；关闭 HTTP 服务或 watcher 时移除监听并 abort，待运行任务不能继续写入或 reload。内容不变时不重写；改变内容通过临时文件和原子 rename 发布，不直接截断既有模板。
- bootstrap 新增依赖时同步维护 `scripts/app-template.ts` 的 `inputs`；静态列表遗漏会让开发热更新使用旧内联代码。

## 尚未覆盖或需要产品决策的风险

以下不是“所有问题已消失”的保证，也不能在没有证据时当成已确认缺陷：

1. **WebKit 与真实设备**：Chromium、Firefox 已执行完整浏览器回归；WebKit 已下载但启动检查报告缺少 libgtk-4、libgraphene、libxslt 及其他运行库，未执行到应用。没有为测试擅自安装系统依赖。真实触屏取消、屏幕阅读器和系统剪贴板权限仍需设备测试，模拟 Promise 不等于系统剪贴板保证。
2. **更广的路由竞争**：乱序、取消确认、同路径外部导航和卸载已用可控 transport 验证，正常 beforeNavigate 接线与 back/forward 有浏览器回归。仍不保证覆盖 SvelteKit 任意插件/拦截器和网络故障组合；已经发生的 History 写入没有事务回滚。新增导航拦截器必须重跑取消/确认用例。
3. **组合数量与外部故障**：resize 隐藏焦点及空查询恢复已有回归，但任意排序、分页、主题、窗口切换和 URL 恢复组合不可能由这些代表用例穷尽。真实文件权限/磁盘错误及多进程同时生成模板仍需专门注入。正在进行的 Bun.build 计算不能被 AbortSignal 强行停止；取消阻止其结果发布，不声称回滚已经开始的原子提交系统调用。
4. **独立设计原型**：HTML 原型有自己的主题、视图、复制和弹窗实现，不属于生产入口。生产组件修复不代表原型也已同步；如重新作为实现起点，必须单独审核。

## 开发验证命令

项目脚本依赖 Bun（包括 bootstrap 构建和测试）；这里沿用仓库已有工具链，不更换包管理器。

```sh
bun test
bun run check
bun run data:check
bun run format:check
bun run build
bun run test:e2e
```

浏览器测试需要已经安装 Chromium。默认由 Playwright 启动**当前生产构建**并独占端口；端口占用时不要杀掉不属于本项目的服务，也不要让测试悄悄复用它：

```sh
# 使用空闲端口（POSIX shell）
PERIODICITY_TEST_PORT=4187 bun run test:e2e -- --workers=2

# 只在确认是目标构建时显式测试已有服务；此时 Playwright 不启动服务
PERIODICITY_TEST_URL=http://127.0.0.1:4187 bun run test:e2e

# 可选的多引擎回归；先按宿主环境安装浏览器及所需系统运行库
bunx playwright install --with-deps firefox webkit
PERIODICITY_TEST_PORT=4187 PERIODICITY_TEST_BROWSERS=chromium,firefox,webkit bun run test:e2e
```

修改 `.svelte` 后必须重新 build 再跑 E2E；仅修改测试不需要重新构建。正常交互用例先检查 `data-app-ready`，避免把预渲染、错误站点或未完成初始化的 DOM 当作运行结果；专门验证首屏加载失败的用例则明确检查 pending → failed → ready，以及失败时正文仍隐藏。
